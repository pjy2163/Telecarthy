# 접수양식 7번 참고자료 문구

텔레CAR시의 Pleos Connect 실행 데모를 제출합니다. 차량용 APK, 소스 코드 및 실행 안내, 실제 에뮬레이터 화면을 녹화한 시연 영상을 포함합니다. 주변 참여자 매칭, 연결 요청·수락, 실제 양방향 음성 통화, 음소거·종료 흐름을 구현했습니다. 공식 Pleos TextToSpeech SDK로 연결 상태를 안내합니다.

위치는 고정된 가상 좌표를 사용하며, 실제 FusedLocation·Gleo 연동과 주행 중 사용 검증은 후속 개발 범위입니다. 시연 영상은 터치 조작을 사용한 무음 화면 녹화입니다.

소스와 APK 파일은 저장소 또는 다운로드 가능한 압축 파일로 제출할 수 있도록 준비했습니다. 실제로 제출할 링크 또는 첨부 파일명을 아래에 기재합니다.

- 시연 영상: 텔레CAR시_Pleos_데모시연.mp4
- 소스와 APK: 텔레CAR시_검토된소스와APK.zip
- APK 경로: telecar-demo/apk/telecarsee_demo_release.apk

공식 APK 파일명 규칙에 맞추려면 팀명이 확정된 후 해당 파일명을 변경하고 README의 경로도 함께 수정합니다.
