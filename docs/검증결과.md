# 텔레CAR시 데모 검증 결과

2026년 11월 15일에 정지된 Pleos Connect 개발 에뮬레이터에서 검증했습니다.

## 환경

- Pleos Connect 2.1.0 API 34 ARM64, 화면 2560×1440
- Kotlin 2.1.21, Jetpack Compose, Gradle 8.13, Android Gradle Plugin 8.9.3
- minSdk 28, compileSdk 35, targetSdk 34
- Pleos TextToSpeech SDK 3.3.1 ON_DEVICE
- LiveKit Android SDK 2.20.3, 로컬 LiveKit 서버 1.13.11
- Chrome 테스트 클라이언트의 합성 마이크 입력과 에뮬레이터 마이크

송수신 수치는 통화 중 특정 시점의 샘플입니다. 음질·지연·실차 주행 성능의 보장값이 아닙니다. 상세 기계 판독 결과는 `native-audio-test.json`, `browser-audio-test.json`에 있습니다. 통화 내용을 녹음하지 않고 메타데이터와 패킷 카운터만 확인했습니다.

## 후속 검증 범위

실제 FusedLocation 위치·도로 판별, Gleo 음성 명령, CarUxRestrictions 변경 처리, 실차 오디오 정책·차내 소음·에코, 네트워크 이동 및 주행 중 사용 허용 여부는 후속 개발·검증 범위입니다. 이번 시연은 가상 위치와 터치 조작을 사용합니다. 영상은 무음 화면 녹화입니다.

APK와 화면에 표시한 기능 범위가 이 설명과 일치하도록 구성했습니다.
